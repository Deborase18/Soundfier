# SOUNDFIER
### Interface Inteligente de Acessibilidade Digital por Comandos de Voz para Serviços Municipais

---

## Sobre o projeto

O **SOUNDFIER** é um projeto de tecnologia voltado à acessibilidade digital, desenvolvido com a proposta de facilitar o acesso dos cidadãos aos serviços públicos municipais por meio de comandos de voz.

A plataforma busca tornar a utilização dos canais digitais da prefeitura mais simples, inclusiva e acessível, permitindo que o cidadão realize consultas, solicitações e agendamentos sem depender exclusivamente da navegação tradicional por telas e menus.

O sistema também oferece a possibilidade de interação por texto, proporcionando uma alternativa para diferentes necessidades de utilização.

O projeto foi idealizado especialmente para pessoas com deficiência motora, dificuldades de navegação digital, idosos e cidadãos com baixo letramento digital, contribuindo para uma experiência mais independente e inclusiva.

## Objetivo geral

Desenvolver uma interface inteligente e acessível que utilize comandos de voz para facilitar a comunicação entre os cidadãos e os serviços públicos municipais, promovendo inclusão digital, autonomia e praticidade no atendimento.

## Objetivos específicos

- Facilitar o acesso aos serviços municipais por meio de comandos de voz.
- Oferecer uma alternativa de navegação por texto.
- Simplificar a realização de consultas e solicitações.
- Disponibilizar informações de maneira clara e objetiva.
- Permitir o acompanhamento do histórico de solicitações.
- Promover acessibilidade para pessoas com diferentes necessidades.
- Garantir maior praticidade e segurança na utilização dos serviços digitais.

---

## Fluxo geral de funcionamento

O funcionamento do SOUNDFIER foi planejado para seguir uma sequência simples:

1. O cidadão acessa a plataforma.
2. Realiza sua identificação.
3. Escolhe entre utilizar comandos de voz ou digitar sua solicitação.
4. O sistema interpreta a intenção informada.
5. Apresenta o serviço correspondente.
6. O cidadão confirma a operação.
7. O sistema apresenta o resultado ou registra a solicitação.
8. As informações ficam disponíveis para consulta e acompanhamento, conforme o serviço.
9. O cidadão pode fornecer um feedback sobre a experiência.

## Desenvolvimento

O desenvolvimento do SOUNDFIER está organizado em etapas:

1. Elaboração dos protótipos de interface.
2. Desenvolvimento do frontend.
3. Implementação do reconhecimento de voz.
4. Desenvolvimento do backend e das rotas.
5. Modelagem e implementação do banco de dados.
6. Integração entre frontend, backend e banco de dados.
7. Testes de funcionamento e acessibilidade.
